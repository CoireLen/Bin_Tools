# BinTools

二进制文件数据重组 TUI 工具。支持顺序/交错格式互转、拆分文件、合并文件。

## 术语说明

| 名称 | 格式 | 说明 |
|------|------|------|
| **顺序** | `111222` | 数据按组连续排列：组1全部元素 → 组2全部元素 → ... → 组N全部元素 |
| **交错** | `121212` | 数据按位置交叉排列：组1[0],组2[0],...,组N[0], 组1[1],组2[1],... |

**示例 (12 个元素, N=3)：**

```
顺序 (111222):  A B C D  E F G H  I J K L
                 ─组1──   ─组2──   ─组3──

交错 (121212):  A E I  B F J  C G K  D H L
```

## 功能

### 1. 顺序 → 交错

将顺序排列的二进制文件转换为交错排列。

- 输入格式：`111222`（组1连续、组2连续...）
- 输出格式：`121212`（各组元素交叉排列）
- 输出文件：`{原名}_s2i_{N}_{类型}.{扩展名}`

### 2. 交错 → 顺序

将交错排列的二进制文件还原为顺序排列。

- 输入格式：`121212`（各组元素交叉排列）
- 输出格式：`111222`（组1连续、组2连续...）
- 输出文件：`{原名}_i2s_{N}_{类型}.{扩展名}`

### 3. 顺序拆分文件

将顺序排列的数据按组拆分为 N 个独立文件。

- 输入格式：`111222`
- 输出：N 个文件，每个文件包含一组数据
- 输出文件：`{原名}_split_001.{ext}`, `{原名}_split_002.{ext}`, ...

### 4. 交错拆分文件

将交错排列的数据按组拆分为 N 个独立文件。

- 输入格式：`121212`
- 输出：N 个文件，每个文件包含从交错数据中分离出的一组
- 输出文件：`{原名}_split_001.{ext}`, `{原名}_split_002.{ext}`, ...

### 5. 顺序合并文件

将多个拆分文件按顺序合并为一个文件。

- 输入：通过文件列表逐个添加拆分文件
- 输出格式：`111222`（文件1 + 文件2 + ... + 文件N 顺序拼接）
- 输出文件：`{原基名}_merged_seq.{ext}`

### 6. 交错合并文件

将多个拆分文件按交错方式合并为一个文件。

- 输入：通过文件列表逐个添加拆分文件
- 输出格式：`121212`（各组元素交叉合并）
- 输出文件：`{原基名}_merged_int.{ext}`

## 支持的数据类型

| 类型 | 大小 | 说明 |
|------|------|------|
| u8   | 1 byte | 无符号 8 位整数 |
| u16  | 2 bytes | 无符号 16 位整数 |
| u32  | 4 bytes | 无符号 32 位整数 |
| f32  | 4 bytes | 32 位浮点数 |
| f64  | 8 bytes | 64 位浮点数 |

## 使用方法

### 编译运行

```bash
cargo run
# 或指定文件路径
cargo run -- /path/to/your/file.bin
```

### TUI 操作

1. **操作模式** — 使用 `← →` 切换，或 `Enter` 展开下拉列表选择
2. **文件路径** — 输入二进制文件路径（合并模式下 Enter 添加到文件列表，可逐个添加多个文件）
3. **文件列表** — 合并模式下显示已添加的文件，支持 ↑↓ 选择、Del 删除
4. **分组数 N** — 输入组数（正整数，仅非合并模式显示）
5. **数据块类型** — 使用 `← →` 切换，或 `Enter` 展开下拉列表选择
6. **执行** — 聚焦后按 `Enter` 执行

### 快捷键

| 按键 | 功能 |
|------|------|
| `Tab` / `↓` | 下一字段（循环） |
| `↑` | 上一字段（循环） |
| `Enter` | 确认 / 执行 / 打开选择列表 |
| `Space` | 打开选择列表（模式/数据类型） |
| `← →` | 切换模式 / 数据类型 |
| `q` / `Esc` | 退出 |

### 拆分文件命名规则

拆分操作输出文件后缀为 `001` ~ `999`：

```
原始文件: data.bin
  → data_split_001.bin
  → data_split_002.bin
  → data_split_003.bin
  → ...
```

### 合并文件列表

合并模式下，文件输入变为可添加的列表：

1. 在“添加文件”输入框中输入文件路径
2. 按 `Enter` 将文件添加到列表
3. 重复添加直到所有文件都已加入
4. 用 `↓` 移到文件列表，`↑↓` 选择文件，`Del` 删除不需要的文件
5. 再按 `↓` 继续到数据类型和执行

## 构建

```bash
cargo build --release
```

产物位于 `target/release/BinTools`。

## 技术栈

- **Rust** — 核心语言
- **ratatui** — TUI 框架
- **crossterm** — 终端控制
