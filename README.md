# BinTools

二进制文件数据重组 TUI 工具。

## 功能

### 数据拆分与交叉重组

将一份二进制文件按指定数据块大小统计元素总数，平均拆分为 N 组，然后按组交叉合并（1, 2, 3, 4...N 顺序），实现数据顺序的重新组织。

**处理流程：**

1. 读取原始文件，按选择的数据类型（u8/u16/u32/f32/f64）计算元素总数
2. 将元素平均分为 N 组（最后一组可能略多）
3. 按交叉顺序输出：`组1[0], 组2[0], ..., 组N[0], 组1[1], 组2[1], ..., 组N[1], ...`

**示例：** 文件含 12 个 u8 元素 `[A B C D E F G H I J K L]`，分为 3 组：

| 组 | 元素 |
|----|------|
| 组1 | A B C D |
| 组2 | E F G H |
| 组3 | I J K L |

交叉合并后输出：`A E I B F J C G K D H L`

## 支持的数据类型

| 类型 | 大小 |
|------|------|
| u8   | 1 byte |
| u16  | 2 bytes |
| u32  | 4 bytes |
| f32  | 4 bytes |
| f64  | 8 bytes |

## 使用方法

### 编译运行

```bash
cargo run
# 或指定文件路径
cargo run -- /path/to/your/file.bin
```

### TUI 操作

1. **文件路径** — 输入二进制文件路径（支持 Tab 传入命令行参数）
2. **分组数 N** — 输入要拆分的组数（正整数）
3. **数据块类型** — 使用 `← →` 切换，或 `Enter` 展开下拉列表选择
4. **执行** — 聚焦后按 `Enter` 执行

输出文件自动保存在原文件同目录下，命名格式：`{原文件名}_interleaved_{N}_{类型}.{原扩展名}`

### 快捷键

| 按键 | 功能 |
|------|------|
| `Tab` / `↓` | 下一字段 |
| `↑` | 上一字段 |
| `Enter` | 确认 / 执行 |
| `← →` | 切换数据类型 |
| `q` / `Esc` | 退出 |

## 构建

```bash
cargo build --release
```

产物位于 `target/release/BinTools`。

## 技术栈

- **Rust** — 核心语言
- **ratatui** — TUI 框架
- **crossterm** — 终端控制
